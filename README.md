### 🌱 About my journey

I'm currently in my final year of **Computer Science and Engineering (IoT)**, learning
by building — not just following tutorials, but actually shipping projects end-to-end:
from data preprocessing, to model training, to deploying something a real user can
click through.

- 🔭 Currently working on **Brain Tumor Detector** — an MRI classification system using
  CNNs, transfer learning (VGG16/ResNet50), and LLM-generated diagnostic reports.
- 🌱 Learning: Deep Learning, Computer Vision, and how to actually deploy ML models
  instead of leaving them in a notebook.
- 🤝 Open to collaborating on ML/DL projects, especially anything healthcare or
  IoT-related.
- ⚡ Fun fact: most of what's below, I learned by breaking it first.
