### 🌱 About my journey

I'm currently in my final year of **Computer Science and Engineering (IoT)**, learning
by building — not just following tutorials, but actually shipping projects end-to-end:
from data preprocessing, to model training, to deploying something a real user can
click through.

- 🔭 Currently working on **Brain Tumor Detector** — an MRI classification system using
  CNNs, transfer learning (VGG16/ResNet50), and LLM-generated diagnostic reports.
- 🌱 Learning: Deep Learning, Computer Vision, and how to actually deploy ML models
  instead of leaving them in a notebook.
- 🤝 Open to collaborating on ML/DL projects, especially anything healthcare or
  IoT-related.
- 💼 Preparing for campus placements — targeting SDE roles at product-based companies.
- ⚡ Fun fact: most of what's below, I learned by breaking it first.

**[Brain Tumor Detector](https://github.com/pranjalrastogi25/brain-tumor-detector)**
MRI-based brain tumor classification (Glioma / Meningioma / Pituitary / No Tumor) using
CNNs and transfer learning, with a Gemini-powered natural-language report generator and
a Streamlit web interface. Final year project — still actively improving it.
<br/>`Python` `TensorFlow/Keras` `OpenCV` `Streamlit` `Gemini API`

**[DocMinimizer](https://github.com/pranjalrastogi25/docminimizer-)**
A MERN-stack PDF text-minimization tool that extracts and rebuilds documents to reduce
file size while preserving structure — using `pdfjs-dist` for extraction and `pdf-lib`
for reconstruction.
<br/>`MongoDB` `Express` `React` `Node.js` `pdf-lib`
